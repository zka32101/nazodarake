# 効果音アセットについて

このディレクトリには本来、以下の効果音ファイル（mp3等）を配置します。
**本リポジトリには実際の音声バイナリは同梱されていません。**
リリース前に、著作権をクリアした音声ファイルをこのディレクトリに追加してください。

| ファイル名 | 用途 |
|---|---|
| `correct.mp3` | 正解時の効果音 |
| `wrong.mp3` | 不正解時の効果音 |
| `tap.mp3` | ボタンタップ時の効果音 |
| `achievement.mp3` | 実績解除時の効果音 |

## 実装上の注意

- 再生ロジックは `lib/services/sound_service.dart` の `SoundService` に実装されています。
- ファイルが存在しない状態で再生を試みても、`try-catch` で例外を握りつぶしログ出力のみ行うため、
  **アプリがクラッシュすることはありません**。
- `pubspec.yaml` の `flutter.assets` に `assets/sounds/` を宣言済みです。実際にファイルを追加した後、
  改めて `flutter pub get` を実行してください。
